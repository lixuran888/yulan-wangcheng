# 为什么可以用 LLM 模拟不同网络结构下的舆论传播

本文档用于说明：为什么在“多网络结构下的多智能体舆论传播仿真系统”中，可以使用大语言模型（LLM）作为智能体的语言、记忆和社会行为生成模块，并结合复杂网络模型研究舆论传播。

核心观点是：

**LLM 不应被理解为“真实人类的完全替代品”，而应被理解为一种可控的、可重复实验的、具有语言行为生成能力的社会模拟组件。网络结构负责约束传播路径，传播动力学模型负责约束激活与状态转移，LLM 负责生成符合人设、记忆、关系和情境的具体言论。**

## 1. 舆论传播本身适合用网络模型表示

舆论传播不是孤立个体的独立选择，而是发生在社会关系网络中的互动过程。

不同网络结构会带来不同传播效果：

- 随机网络强调陌生人之间的随机接触。
- 小世界网络强调熟人圈层和少量捷径。
- 无标度网络强调意见领袖、超级节点和幂律影响。
- 规则网络强调邻里式缓慢传播。
- 社区网络强调群体内部强化和跨群体桥接传播。

因此，舆论传播研究天然需要区分：

```text
谁能接触谁
谁更容易影响谁
信息能否跨圈层流动
关键节点是否会造成扩散突变
群体内部是否形成回音室
```

复杂网络模型可以回答“传播路径”和“结构性约束”的问题，但它本身很难回答“具体的人为什么这样说”“言论内容如何变化”“记忆和人设如何影响表达”。这正是引入 LLM 的原因。

## 2. 传统 ABM 的不足

传统 Agent-Based Modeling（ABM，多智能体建模）通常用规则描述个体行为，例如：

```text
如果邻居中超过 30% 支持观点 A，则该个体转向观点 A。
如果信任度高于 0.7，则转发消息。
如果证据强度高于阈值，则进入辟谣状态。
```

这类模型的优点是清晰、可解释、可重复。但不足也很明显：

- 个体表达过于机械。
- 人设差异通常只能写成几个数值参数。
- 很难模拟真实舆论中的犹豫、误解、情绪、含糊表达和社会压力。
- 很难体现记忆、过往经历、关系变化对发言内容的影响。

现实舆论不是只有“传播/不传播”的二元选择。人会说：

```text
我听别人说的，但我也不确定。
这个事情别急着转，先看看有没有官方说明。
我不是替谁说话，我只是觉得不能冤枉人。
如果是真的，那家长肯定接受不了。
```

这些语言细节会影响传播效果，也会影响其他人的情绪、信任和判断。传统规则模型难以自然生成这类内容。

## 3. LLM 的适用性来自其训练机制

大语言模型通过大规模文本数据训练获得语言模式、语义关系、常识表达和对话结构能力。其训练数据通常包含大量来自真实人类社会的文本材料，例如新闻、论坛、网页、百科、问答、评论、对话和公开文本。

从机器学习角度看，LLM 学到的不是某一个人的真实心理，而是大规模语言行为中的统计规律，包括：

- 不同身份的人通常如何表达。
- 不同情绪下语言会如何变化。
- 人在不确定、质疑、辟谣、安慰、争论时常见的话语结构。
- 社会关系如何影响说话方式。
- 事件信息如何被转述、压缩、误解和放大。

因此，LLM 特别适合补上传统 ABM 缺少的一层：

```text
ABM / 复杂网络：控制结构与状态
LLM：生成具体语言行为
```

在舆论传播研究中，我们并不是让 LLM “凭空决定整个社会如何变化”，而是把它放在严格约束下使用：

- 网络结构决定可交流对象。
- 动力学公式决定是否被激活。
- 个体参数决定敏感度、信任度、阈值和情绪。
- 人设和记忆决定语言内容。
- 系统记录每一步传播证据。

这样可以避免 LLM 完全自由发挥，也能保留自然语言模拟的优势。

## 4. LLM 能模拟“异质个体”

舆论传播研究中很重要的一点是：个体不是同质的。

不同人有不同的：

- 年龄、职业、教育背景。
- 家庭关系和社会关系。
- 情绪强度。
- 对他人意见的敏感度。
- 对社会联系的重视程度。
- 怀疑倾向。
- 社会责任感。
- 过往记忆。
- 对事件的初始立场。

LLM 可以通过 persona prompt、记忆流和关系上下文生成差异化表达。例如：

- 家长可能更关注孩子安全。
- 幼儿园内部人员可能更谨慎、害怕承担责任。
- 老街坊可能更依赖熟人经验。
- 专业人士可能更强调证据链和流程。
- 青少年可能更容易受线上讨论影响。

这使系统可以模拟“同一事件在不同社会位置的人那里如何被理解和表达”。

这并不意味着 LLM 生成的每句话都等于真实人类行为，而是说明它可以作为“语言化异质智能体”的生成器，用来增强 ABM 的表达能力。

## 5. LLM 与记忆系统结合后更接近社会互动

Stanford Generative Agents 的核心贡献之一，是把 LLM 与记忆、反思、计划和社会互动结合起来，使智能体不只是一次性回答问题，而是能在连续时间中积累经验。

在舆论传播场景中，这一点非常重要。

如果没有记忆，智能体每次发言都像重新开始，容易出现：

- 前后矛盾。
- 关系不连续。
- 忘记之前听过什么。
- 忘记自己曾经质疑或相信过什么。
- 洞察和反思显得虚假。

如果有记忆流，智能体可以基于：

- 自己原有的人设。
- 过去与他人的对话。
- 最近听到的消息。
- 对事件的反思。
- 对某个人信任度的变化。

生成更连续、更符合情境的表达。

因此，本系统保留原版记忆流逻辑是合理的：传播模型负责宏观约束，记忆系统负责微观连续性。

## 6. LLM 适合补足舆论传播中的“内容层”

传统传播模型通常研究的是：

```text
观点是否采纳
节点是否感染
信息是否转发
传播规模是否扩大
```

但真实舆论传播不仅有“是否传播”，还有“传播了什么”。

同样的信息可能被说成：

```text
幼儿园食物中毒了。
听说是食材不新鲜。
别乱传，可能只是孩子肠胃炎。
监管部门已经介入了，等结果。
有人早就提醒过食堂有问题。
```

这些内容差异会影响：

- 情绪强度。
- 可信度。
- 是否引发恐慌。
- 是否激发质疑。
- 是否促成辟谣。
- 是否跨社区传播。

LLM 的价值就在于，它可以根据人设、关系和记忆生成不同表达，从而使模型不仅记录“传播状态”，还记录“言论内容变化”。

这对论文很重要，因为它可以让研究对象从单纯的状态扩散变成：

```text
结构扩散 + 情绪扩散 + 语义演化 + 关系演化
```

## 7. 为什么可以模拟不同网络结构

LLM 本身不决定网络结构。网络结构由复杂网络模型生成。

因此，同一个 LLM 智能体系统可以放到不同网络中比较：

- 在随机网络中，陌生人连接会造成较分散、偶然的传播。
- 在小世界网络中，局部熟人圈会形成快速局部强化，并通过捷径扩散。
- 在无标度网络中，Hub 节点会显著放大传播。
- 在规则网络中，信息传播更慢、更依赖邻近关系。
- 在社区网络中，群体内部强化明显，跨群体传播依赖桥接节点。

在这里，LLM 的作用不是替代网络科学，而是让每种网络结构下的节点行为更接近真实社会互动。

可以把系统理解为三层：

```text
第一层：网络结构
决定谁能遇到谁。

第二层：传播动力学
决定谁被激活、谁沉默、谁质疑、谁辟谣。

第三层：LLM 智能体
决定这个人在当前人设、记忆和关系下具体怎么说。
```

这种分层设计使得系统既有数学约束，也有语言生成能力。

## 8. 当前 LLM 发展为该方法提供了技术基础

近年来 LLM 能力快速提升，使其越来越适合作为社会模拟中的生成式智能体模块。

主要原因包括：

- 模型规模和训练数据规模提升，使其具有更强的语言理解与生成能力。
- 指令微调和对齐技术提升了模型遵循复杂任务说明的能力。
- 长上下文能力增强，使模型可以读取更长的人设、记忆和关系信息。
- 工具调用和结构化输出能力增强，使模型可以与仿真系统结合。
- 多智能体框架发展，使多个 LLM 角色可以在同一环境中连续互动。

这并不意味着 LLM 已经能完全替代真实人类实验，但它已经足以作为一种“可控的生成式社会模拟组件”参与计算社会科学研究。

## 9. 学术依据

已有研究已经开始使用 LLM 或 LLM agents 进行社会模拟、人类行为模拟和舆论动力学研究。

### 9.1 Generative Agents

Park 等人的 Stanford Generative Agents 研究提出，基于 LLM 的生成式智能体可以在沙盒环境中形成记忆、反思、计划和互动，并产生较可信的社会行为。

参考：

- Joon Sung Park et al., *Generative Agents: Interactive Simulacra of Human Behavior*, 2023.  
  https://huggingface.co/papers/2304.03442

### 9.2 LLM 用于人类行为模拟

Aher、Arriaga 和 Kalai 提出用 LLM 模拟多个人类受试者，并复现实验研究中的行为模式。这类研究说明，LLM 可以作为“合成参与者”参与社会科学实验模拟，但也需要评估其偏差。

参考：

- Gati Aher, Rosa I. Arriaga, Adam Tauman Kalai, *Using Large Language Models to Simulate Multiple Humans and Replicate Human Subject Studies*, ICML 2023.  
  https://www.microsoft.com/en-us/research/publication/using-large-language-models-to-simulate-multiple-humans-and-replicate-human-subject-studies/

### 9.3 LLM 增强的 ABM 综述

Gao 等人的综述系统讨论了 LLM 如何增强 Agent-Based Modeling and Simulation，尤其适用于复杂社会行为、异质个体、自然语言互动和社会系统仿真。

参考：

- Chen Gao et al., *Large language models empowered agent-based modeling and simulation: a survey and perspectives*, Humanities and Social Sciences Communications, 2024.  
  https://www.nature.com/articles/s41599-024-03611-3

### 9.4 LLM 与舆论动力学

已有研究开始直接把 LLM agents 与 opinion dynamics 结合，用于模拟社会网络中的观点演化和影响扩散。

参考：

- Yun-Shiuan Chuang et al., *Simulating Opinion Dynamics with Networks of LLM-based Agents*, Findings of NAACL 2024.  
  https://www.researchgate.net/publication/382626430_Simulating_Opinion_Dynamics_with_Networks_of_LLM-based_Agents

- Junchi Yao et al., *Social opinions prediction utilizes fusing dynamics equation with LLM-based agents*, Scientific Reports, 2025.  
  https://www.nature.com/articles/s41598-025-99704-3

- Lan Zhang et al., *LLM-AIDSim: LLM-Enhanced Agent-Based Influence Diffusion Simulation in Social Networks*, Systems, 2025.  
  https://www.mdpi.com/2079-8954/13/1/29

这些研究共同说明：把 LLM agents 与传统动力学方程、社会网络和 ABM 结合，已经成为一个正在发展的研究方向。

## 10. 方法边界

为了让论文更严谨，必须明确 LLM 模拟的边界。

LLM 不能直接等同于真实人类，原因包括：

- 训练数据存在偏差。
- 模型可能倾向于生成“看起来合理”的回答。
- 不同模型、不同 prompt 会导致不同结果。
- 模型可能过度理性或过度迎合指令。
- 生成结果存在随机性。
- 真实社会中的制度、利益、恐惧、线下压力不能完全被文本模拟。

因此，论文中不应写成：

```text
LLM 可以完全模拟真实社会舆论。
```

更合理的表述是：

```text
LLM 可以在明确约束条件下，作为异质语言行为生成模块，增强传统舆论传播模型对个体表达、记忆连续性和社会互动内容的模拟能力。
```

也就是说，本系统模拟的是“理论控制环境下的舆论传播机制”，不是直接预测现实社会的唯一结果。

## 11. 为什么本系统的设计是合理的

本系统没有让 LLM 完全自由地决定传播过程，而是采用分层约束：

| 层级 | 负责内容 | 研究意义 |
|---|---|---|
| 复杂网络结构 | 谁能接触谁 | 比较不同网络拓扑对传播的影响 |
| 传播动力学模型 | 是否激活、传播、质疑、辟谣、沉默 | 保证传播过程有数学约束 |
| 人设与记忆系统 | 个体背景、过往经验、关系连续性 | 保证智能体有异质性和历史连续性 |
| LLM 对话生成 | 具体语言表达 | 记录言论内容、情绪和语义变化 |
| 前端证据记录 | 指标、言论、状态、报告 | 降低黑箱性，服务论文分析 |

因此，本系统不是“用 LLM 随机聊天”，而是：

```text
用网络模型约束连接，
用动力学模型约束传播，
用记忆系统约束连续性，
用 LLM 生成自然语言行为，
用证据记录解释传播结果。
```

这种设计在方法上比单纯聊天模拟更可控，也比传统规则 ABM 更接近真实舆论互动。

## 12. 可写入论文的方法论表述

可以在论文中这样概括：

> 本研究将大语言模型引入多智能体舆论传播仿真，并非将 LLM 视为真实人类的完全替代，而是将其作为异质智能体的自然语言行为生成模块。复杂网络模型用于约束智能体之间的接触结构，传播动力学方程用于约束个体激活、传播、质疑和辟谣状态，记忆系统用于维持个体经历与社会关系的连续性，LLM 则根据人设、记忆、关系和情境生成具体言论。该方法能够在保留数学可解释性的同时，引入传统 ABM 难以表达的语言内容、情绪变化和社会互动细节，为研究不同网络结构下的舆论扩散机制提供一种可解释的生成式仿真路径。

## 13. 结论

使用 LLM 模拟不同网络结构下的舆论传播是有方法基础的。

它的合理性来自三点：

第一，舆论传播本来就是网络化、互动式、语言化的社会过程。  
第二，LLM 经过大规模人类文本训练，具备生成差异化语言行为和社会互动表达的能力。  
第三，将 LLM 放入复杂网络和传播动力学约束中，可以同时获得自然语言真实性与模型可解释性。

但这种方法必须保持谨慎：LLM 生成结果不能直接等同于现实社会，只能作为理论控制环境下的生成式模拟。后续研究应通过真实数据校准、参数敏感性分析、多模型对比、重复实验和人工编码验证来提升可信度。
