# 社区网络结构传播模型交接记录

本文档用于记录“社区网络结构”版本后续做过的关键修改，方便交接、复盘和论文写作时引用。当前版本的目标不是追求运行速度，而是尽量恢复 Stanford Generative Agents 原版的人设、记忆、对话与反思逻辑，同时用传播动力学模型约束“谁和谁交流、何时被激活、采取何种传播行为”。

## 1. 当前版本定位

当前只保留并重点实现一个网络类型：

**社区网络 Community Network**

该网络用于模拟熟人社会、兴趣部落、小镇公共议题讨论等场景。网络内部存在多个紧密小群体，群体之间通过少量桥接关系传播信息。

当前采用的传播约束模型为：

**Community-aware Weighted Complex Threshold Model**

中文可理解为：

**社区感知加权复杂阈值模型**

模型思路是：  
每个智能体是否参与传播，不只看是否听到消息，还要看消息来自谁、双方关系强弱、是否同社区、对方情绪强度、自己对他人意见的敏感度、自己对社会联系的重视程度，以及当前累计传播压力是否超过个人阈值。

## 2. 社区划分

当前社区划分是为了先跑通“小镇公共事件传播”场景，属于人工设定版本，后续可以替换为 LFR 或真实社交数据。

| 社区 | 含义 | 典型角色 |
|---|---|---|
| 0 | 家长与受害者相关群体 | 李大强、张国庆等 |
| 1 | 幼儿园内部相关群体 | 林小雨、刘小敏等 |
| 2 | 小镇公共讨论群体 | 王丽华、陈思远、周小艺等 |
| 3 | 制度与专业知识群体 | 教育、监管、公共卫生、社区协调相关人物 |
| 4 | 青少年与线上扩散群体 | 高建国、韩小雪等 |

网络连边规则：

- 同社区内部连接更密集，表示熟人圈、工作圈或兴趣圈。
- 原版小镇人物关系会被保留，并转化为传播边权。
- 跨社区边较少，只保留少量桥接人物。
- 桥接边在传播中有额外解释意义，用来观察信息如何跨圈层扩散。
- 当前实现保证没有孤立节点，避免某些智能体永远无法参与传播。

## 3. 传播动力学约束

每一步仿真中，系统先根据网络结构和关系强度选择可能发生交流的智能体对，再判断目标智能体是否被激活。

### 3.1 单条边的影响力

一条传播边的影响力由以下因素共同决定：

```text
I_ji = w_ji * trust_ji * communityFactor * bridgeBonus * sourceEmotion * actionWeight
```

含义：

- `w_ji`：网络边权。
- `trust_ji`：目标对来源的信任度，会随对话动态变化。
- `communityFactor`：同社区传播权重更高，跨社区传播权重更低。
- `bridgeBonus`：桥接边有额外解释权重。
- `sourceEmotion`：来源情绪越强，传播压力越大。
- `actionWeight`：传播、质疑、辟谣、反思等行为对目标产生不同影响。

### 3.2 个体累计传播压力

```text
H_i = Σ I_ji
```

`H_i` 表示智能体当前受到的综合传播压力。它来自多个邻居，而不是单一消息。

### 3.3 个体激活阈值

```text
theta_i = 0.55 - 0.20 * OSI_i - 0.15 * emotion_i + 0.15 * skepticism_i - 0.10 * CPI_i
```

含义：

- `OSI`：意见感知指数，越高表示越容易受他人意见影响。
- `CPI`：连通性感知指数，越高表示越重视社会联系。
- `emotion`：当前情绪强度。
- `skepticism`：怀疑倾向，越高越不容易直接传播。
- `theta`：被激活阈值，越低越容易参与讨论。

### 3.4 行为决策

当 `H_i` 接近或超过 `theta_i` 时，智能体才更可能参与对话。行为分为：

- `share`：传播或交流。
- `question`：质疑。
- `debunk`：辟谣或纠偏。
- `silent / ignore`：沉默或暂不参与。

行为不是随机标签，而是由传播压力、信任、证据强度、怀疑倾向、社会责任感等共同决定。

## 4. 人设、记忆与对话逻辑

后续修改的重点是：不能为了快而牺牲真实感。

当前已经恢复的逻辑：

- 读取原版 Stanford 小镇人物的 `scratch` 人设信息。
- 读取原版 `AssociativeMemory` 记忆流。
- 每次对话会写入原版 `add_chat`。
- 每次听到他人言论会写入原版 `add_event`。
- 原版记忆流仍然作为智能体生成对话时的上下文来源。
- 前端轻量记忆只用于展示和统计，不替代原版记忆系统。

对话生成逻辑：

- 传播模型只决定“谁和谁说、是否被激活、采取什么传播行为”。
- 具体说什么交给大语言模型生成。
- Prompt 中会传入人物人设、当前状态、双方关系、近期记忆、原版记忆流片段、传播行为。
- 若 DeepSeek API 不可用，才使用本地兜底话术。

也就是说，最终目标是让“数学模型控制传播结构”，让“人设与记忆控制语言内容”。

## 6. 人际关系动态变化

人际关系不是固定不变的。

每次对话后，系统会根据行为类型和情绪强度调整信任关系：

- 支持性交流可能提高信任。
- 高情绪传播可能加强影响，也可能造成关系压力。
- 质疑会带来轻微信任波动。
- 辟谣会影响对消息来源的可信度判断。

变化后的 `trust` 会继续进入传播公式，影响下一轮传播。因此当前版本已经形成：

```text
对话内容 -> 情绪/行为 -> 关系变化 -> 传播压力变化 -> 下一轮对话对象和行为变化
```

这一点对论文解释很重要，因为它把生成式对话和传播动力学连接起来了。

## 7. 前端展示

当前前端保留并调整了以下板块：

- 左侧：实时舆论言论流，记录所有智能体发言。
- 中间：社区网络结构图，展示节点、连边、传播流动。
- 右侧：个体指标，包括情绪、OSI、CPI、`H/theta`、当前状态。
- 底部：洞察反馈和原版 details 类似的分析信息。
- 顶部：研究证据文档按钮，点击后弹出 Markdown 风格分析文档。

暂停时，传播流动红点应停止显示，避免出现“已经暂停但还在传播”的误解。

## 10. 对论文的参考价值

当前版本对论文的主要价值是：它把生成式智能体的人设、记忆、对话和社会传播模型连接起来。论文中可以用它说明：社区网络中的舆论扩散不是单纯由拓扑决定，而是由社区结构、关系强度、个体阈值、情绪、信任和记忆共同塑造。右侧指标和研究报告弹窗也可以作为解释“为什么某一轮传播发生”的证据链，降低生成式仿真的黑箱感。

## 11. 当前不足

当前版本仍然有明显不足：

- 社区划分仍是人工设定，不是严格的 LFR 基准图或真实社交网络数据。
- 参数还没有做系统敏感性分析。
- 大语言模型输出存在随机性，需要固定随机种子、缓存输出并做多轮重复实验。
- 原版记忆流目前主要是运行时接入，后续应增加实验快照保存。
- 当前只重点实现社区网络，其他网络结构还没有做同等质量的对照实现。
- 兜底话术仍然存在，但正式实验应尽量使用真实模型输出或明确标注。

## 12. 后续建议

后续可以按这个顺序继续改：

1. 用 LFR 基准图或真实社交数据替换人工社区。
2. 给每个社区补充更可信的人设材料和社会背景。
3. 增加 LLM 输出缓存，降低 API 成本并保证实验可复现。
4. 记录每条传播边的证据：来源、目标、`H`、`theta`、动作、情绪、信任变化。
5. 增加参数敏感性实验和消融实验。
6. 再逐步补齐随机网络、小世界网络、无标度网络、规则网络的同质量版本。
