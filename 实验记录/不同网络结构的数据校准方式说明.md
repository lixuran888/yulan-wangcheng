# 不同网络结构的数据校准方式说明

这份文档用来说明：如果我们要让仿真系统更像真实舆论传播，而不是只靠自己设参数，应该怎么用真实数据来校准不同网络结构。

简单说，校准就是：

> 先看看真实世界里的网络和舆论传播大概长什么样，再把我们的仿真参数调到比较接近真实情况。

我们不需要一开始就找到“完美数据”。更现实的做法是分三步：

1. 校准网络长什么样。
2. 校准信息怎么传播。
3. 校准人说话像不像真实评论。

## 1. 先校准什么

每个网络结构都可以从三个层面校准。

| 校准内容 | 通俗解释 | 需要的数据 |
|---|---|---|
| 网络结构 | 人和人之间怎么连 | 社交网络、转发网络、评论互动网络 |
| 传播过程 | 消息怎么扩散、多久扩散、谁会转发 | 转发链、评论时间序列、辟谣记录 |
| 语言内容 | 人们到底怎么说话 | 微博评论、新闻评论、知乎评论、论坛帖子 |

也就是说，我们不是只校准一个数字，而是要让系统同时接近真实社会里的：

- 关系结构；
- 传播速度；
- 情绪强度；
- 质疑和辟谣比例；
- 不同人的说话方式。

## 2. 随机网络怎么校准

随机网络可以理解成：

> 大家互相认识没有明显规律，谁和谁连接比较随机。

它不像真实社交网络那么复杂，更适合作为对照组。

### 怎么校准

先找一个真实社交网络，算出里面平均每个人大概有多少连接。然后用这个平均连接数生成随机网络。

例如真实数据里平均每个人有 6 个互动对象，那么我们就让随机网络里每个节点平均也差不多有 6 条边。

### 需要什么数据

可以用：

- 匿名论坛回复关系；
- 普通评论区互动关系；
- 随机抽样的微博互动关系；
- SNAP 公开社交网络数据。

### 主要看什么指标

```text
节点数量
平均连接数
整体传播规模
平均传播速度
```

### 论文里怎么说

随机网络主要作为基线模型，用来观察“没有熟人圈、没有意见领袖、没有社区结构”的情况下，舆论会怎么传播。

## 3. 小世界网络怎么校准

小世界网络可以理解成：

> 大家都有自己的熟人圈，但也有少数人能把不同圈子连起来。

这很像朋友圈、微信群、小镇熟人社会、班级关系。

### 怎么校准

小世界网络最重要的是两个特征：

- 熟人圈内部很紧密；
- 整个网络里任意两个人之间又不会隔得太远。

所以要用真实数据校准：

```text
平均连接数
聚类系数
平均路径长度
```

通俗说：

- 平均连接数：每个人大概认识几个人。
- 聚类系数：你的朋友之间是不是也互相认识。
- 平均路径长度：一个消息从一个人传到另一个人平均要经过几步。

### 需要什么数据

可以用：

- Facebook ego network；
- 班级关系；
- 公司内部交流关系；
- 微信群或 QQ 群互动记录，前提是合法匿名；
- SNAP 的 `ego-Facebook` 数据。

### 论文里怎么说

小世界网络适合模拟熟人社会中的舆论传播，尤其适合观察消息如何在小圈子里快速强化，又如何通过少量桥接关系扩散出去。

## 4. 无标度网络怎么校准

无标度网络可以理解成：

> 少数人特别有影响力，大多数人连接很少。

这很像微博大 V、明星、头部博主、意见领袖。

### 怎么校准

重点看真实网络里有没有“超级节点”。

需要统计：

```text
度分布
Top 1% 节点连接占比
Hub 节点数量
转发链宽度
转发链深度
```

通俗说：

- 看是不是少数人连接了很多人；
- 看头部账号是不是能明显放大传播；
- 看消息是横向爆发，还是一层层往下传。

### 需要什么数据

可以用：

- 微博转发链；
- Twitter 转发网络；
- B站 UP 主评论/转发关系；
- YouTube 互动网络；
- SNAP 的 Twitter、LiveJournal、Pokec 数据；
- Hoaxy 虚假信息扩散数据。

### 论文里怎么说

无标度网络适合模拟社交媒体上的意见领袖效应，用来研究 Hub 节点如何放大舆论、制造突发扩散，或者让辟谣信息快速覆盖更多人。

## 5. 规则网络怎么校准

规则网络可以理解成：

> 每个人只和附近几个人联系，消息只能一层一层慢慢传。

它不太像现代开放平台，更像封闭村落、宿舍楼、单位层级、传统邻里关系。

### 怎么校准

规则网络的重点不是找复杂数据，而是确定：

```text
每个人固定连接几个邻居
信息传完全网要多久
有没有远距离捷径
```

如果没有真实数据，也可以把它作为理论对照组。

### 需要什么数据

可以用：

- 村落住户邻近关系；
- 小区楼栋关系；
- 宿舍房间关系；
- 班级座位关系；
- 公司层级通讯录。

### 论文里怎么说

规则网络适合模拟低流动、低跨圈层、低捷径的传统社会结构，用来对比现代社交网络为什么传播更快。

## 6. 社区网络怎么校准

社区网络是当前项目最重要的结构。

它可以理解成：

> 人们分成不同小圈子，小圈子内部聊得很多，小圈子之间靠少数桥接人物传消息。

这很像：

- 豆瓣小组；
- B站分区；
- 微信群；
- 家长群；
- 小镇熟人圈；
- 学校、社区、单位里的不同群体。

### 怎么校准

社区网络要重点看：

```text
社区数量
每个社区有多少人
社区内部连接密不密
社区之间连接多不多
桥接节点是谁
消息跨社区传播要多久
```

对应到论文指标就是：

```text
模块度 Q
社区规模分布
社区内边比例
跨社区边比例
桥接节点中心性
跨社区传播率
```

通俗说：

- 一个圈子内部是不是很容易互相影响；
- 不同圈子之间是不是很难互相影响；
- 哪些人负责把消息从一个圈子带到另一个圈子。

### 需要什么数据

可以用：

- SNAP 的 community 数据；
- `email-Eu-core` 邮件网络；
- `com-Youtube` 社区网络；
- `com-DBLP` 学术合作网络；
- 豆瓣小组、贴吧、B站分区评论；
- 合法匿名的微信群/社区群互动记录；
- MuMiN 虚假信息数据集。

### 论文里怎么说

社区网络最适合研究群体内部强化、回音室效应、跨圈层扩散和桥接节点作用。当前项目里的幼儿园公共事件、小镇讨论、家长群传播，都很适合放在社区网络下分析。

## 7. LLM 说话内容怎么校准

网络结构解决的是“谁和谁接触”，但 LLM 还要解决“这个人怎么说话”。

所以还需要用真实评论校准语言内容。

### 可以采集什么文本

可以找类似公共事件的评论数据，例如：

- 微博热搜评论；
- 新闻评论；
- 知乎问题评论；
- B站评论；
- 小红书评论；
- 论坛帖子；
- 事实核查平台下的讨论文本。

采集时要注意合法合规，不要保存隐私信息。

### 怎么标注

可以先人工标注 300 到 1000 条评论。

每条评论标注：

```text
传播
质疑
辟谣
沉默/观望
情绪强度
是否引用证据
是否攻击他人
是否请求官方回应
是否表达不确定
```

然后和 LLM 生成的言论做对比。

### 对比什么

```text
真实评论里传播类占多少
LLM 生成里传播类占多少

真实评论里质疑类占多少
LLM 生成里质疑类占多少

真实评论平均情绪强度是多少
LLM 生成平均情绪强度是多少

真实评论是否经常引用来源
LLM 是否也会引用来源
```

如果差距很大，就要改 prompt、改人设、改参数，或者重新标注。

## 8. 最推荐的数据来源

### 公开网络数据

SNAP：

```text
https://snap.stanford.edu/data/
```

适合找：

- Facebook ego network；
- Twitter network；
- YouTube community；
- DBLP community；
- email-Eu-core；
- LiveJournal；
- Pokec。

### 网络数据集合

KONECT：

```text
http://konect.cc/
```

适合找更多社交、通信、合作、互动网络。

### 虚假信息和事实核查数据

Hoaxy：

```text
https://ojs.aaai.org/index.php/ICWSM/article/view/14986
```

MuMiN：

```text
https://mumin-dataset.github.io/index
```

这类数据适合校准传播、质疑和辟谣过程。

## 9. 当前项目最建议先做什么

结合我们现在做的是“社区网络 + 小镇公共事件 + LLM 智能体”，最建议先做三件事：

### 第一步：先校准社区网络结构

用 SNAP 的 `email-Eu-core` 或 `com-Youtube` 先提取：

```text
平均度
社区数量
模块度
社区内边比例
跨社区边比例
```

然后把当前项目里的社区网络参数调到类似范围。

### 第二步：校准传播和辟谣比例

找一个公共事件评论数据，人工标注几百条：

```text
多少人在传播
多少人在质疑
多少人在辟谣
多少人在观望
```

然后调整模型里的：

```text
activation_threshold
skepticism
trust_weight
emotion_weight
bridge_bonus
```

### 第三步：校准 LLM 的说话风格

把真实评论和 LLM 生成评论放在一起比较：

```text
是否太像机器人
是否太理性
是否每个人说话都一样
是否符合身份
是否会延续之前记忆
是否有真实的不确定感
```

如果不像，就继续调整人设、记忆摘要和 prompt。

## 10. 一句话总结

不同网络结构的校准方式可以这样理解：

| 网络结构 | 校准重点 |
|---|---|
| 随机网络 | 平均连接数，作为基线对照 |
| 小世界网络 | 熟人圈密度、聚类系数、平均路径 |
| 无标度网络 | 意见领袖、Hub 节点、幂律度分布 |
| 规则网络 | 固定邻居、传播步数、低捷径结构 |
| 社区网络 | 社区数量、模块度、桥接节点、跨社区传播 |

最后要记住：

> 网络数据用来校准“谁能影响谁”，传播数据用来校准“消息怎么扩散”，评论文本用来校准“人到底怎么说话”。

这三层都做好，系统才更像一个可以写进论文的舆论传播仿真实验，而不是单纯的 LLM 聊天演示。
