# 人设 × 网络结构适配矩阵（完整版）

**推导原则**：所有权重和参数偏移均基于各agent的 `information_sources`、`network_behavior`、`trust_in_official` 和 `emotional_baseline` 推导，不是主观贴标签。

**五种网络的隐含媒介语境**：

| 网络类型 | 隐含传播场景 | 主导信息特征 |
|---|---|---|
| 随机网络 | 匿名论坛/陌生人平台 | 情绪驱动，无社会关系背书 |
| 无标度网络 | 微博/短视频，KOL主导 | 病毒扩散，头部节点放大 |
| 小世界网络 | 微信朋友圈/熟人群聊 | 熟人背书，远程桥接有效 |
| 社区网络 | 小区群+面对面，分层结构 | 本地聚合，社区间桥接慢 |
| 规则网络 | 机构/单位内部渠道 | 正式传递，情绪衰减快 |

## 三、网络维度横向总结

### 哪些网络对仿真结果差异最大？

| 网络 | 主导角色 | 预期传播特征 | 理论验证指标 |
|---|---|---|---|
| 随机网络 | 高建国（情绪主导） | 快速分散扩散，极化快，缺乏权威压制 | 传播速度高、覆盖广但深度浅、情绪得分高 |
| 无标度网络 | 高建国+陈思远（双极） | 头部节点放大效应明显，两种极端观点均有Hub | 幂律度分布验证、级联规模大 |
| 小世界网络 | 王丽华+林小雨+陈思远 | 聚类内快速共识，跨圈传播慢 | 聚类系数高、路径长度短、观点分化明显 |
| 社区网络 | 李大强+王丽华+唐晓舒 | 社区内强一致性，子群之间通过桥接慢速传递 | 模块度高、桥接节点识别明确 |
| 规则网络 | 赵明轩+陈立衡+孙宁 | 正式信息传递有序，情绪极化被压制，传播慢 | 传播速度低、情绪得分低、覆盖度受拓扑限制 |

### 刘小敏的特殊性

她是**跨所有网络的关键潜力信源**，但激活条件最苛刻。论文可以设计一个"信源泄露"情节：在社区网络（中度激活）下，当她被林小雨多轮触达后，信息流出并引发级联——这个级联在不同网络中的传播路径差异，可以成为一个独立的仿真对比案例。

## 四、参数偏移的代码映射建议

以下参数偏移建议以字典形式存储在 `simulation_core.py` 的 `NETWORK_SCENARIOS` 或独立的 `AGENT_NETWORK_WEIGHTS` 中，按 `{agent_name: {network_type: {param: delta}}}` 结构组织，在每轮对话前调用覆盖默认值。

```python
AGENT_NETWORK_WEIGHTS = {
    "高建国": {
        "scale_free":  {"emotion_amplification": +0.30, "arousal_threshold": -0.25, "bridge_bonus": +0.15},
        "random":      {"emotion_amplification": +0.25, "arousal_threshold": -0.20, "skepticism": -0.20},
        "small_world": {"emotion_amplification": +0.15},
        "community":   {"emotion_amplification": +0.10, "bridge_bonus": -0.20},
        "regular":     {"activation_weight": 0.10},
    },
    "王丽华": {
        "community":   {"bridge_bonus": +0.30, "emotion_amplification": +0.20, "arousal_threshold": -0.15},
        "small_world": {"bridge_bonus": +0.15, "emotion_amplification": +0.15},
        "scale_free":  {"emotion_amplification": +0.10, "bridge_bonus": -0.10},
        "random":      {"bridge_bonus": -0.30, "activation_weight": 0.30},
        "regular":     {"bridge_bonus": -0.20, "activation_weight": 0.30},
    },
    "刘小敏": {
        "community":   {"activation_weight": 0.50, "anxiety_boost": +0.30},
        "small_world": {"activation_weight": 0.30, "skepticism": +0.30},
        "regular":     {"activation_weight": 0.30, "skepticism": +0.20},
        "scale_free":  {"activation_weight": 0.10},
        "random":      {"activation_weight": 0.10},
    },
    # ... 其余agent同理
}
```
