多网络结构下的多智能体舆论传播仿真系统技术文档
1. 项目目标
本系统用于模拟不同社会网络结构下，多个具有异质人格、认知偏好和关系感知能力的智能体，如何在公共事件中接收、判断、转发、质疑、辟谣或沉默。
系统不再以传统 AI Town 的二维地图作为主要承载界面，而是改为网络结构可视化界面。每个节点代表一个智能体，每条边代表社会关系或信息通道。信息传播时，节点之间的边会出现动态光点，表示观点、谣言、事实信息、情绪或辟谣内容正在流动。
核心研究问题：
不同网络结构、不同智能体人格分布、不同信息内容和干预策略，会如何影响舆论扩散速度、情绪极化、谣言传播、辟谣效率和群体观点演化？
2. 旧系统改造范围
2.1 保留能力
保留以下已有能力，并改造成新架构中的模块：
1. 多源舆情采集能力
用于接入微博、短视频评论、新闻评论或自定义输入文本。
2. 情绪分析能力
不只判断正向、负向、中性，还需要输出情绪强度、争议度、攻击性、焦虑度、信任度等指标。
3. 角色建模能力
原有角色画像、人物关系、长期记忆模块继续保留，但需要从“地图人物”改为“网络节点智能体”。
4. 统计图表能力
保留舆情热度、情绪变化、传播链路、核心节点识别等图表。
5. 舆论传播按钮
原来的“舆论传播”功能保留，但它不再只是展示情感分析结果，而是展示实时传播分析文档、网络指标、关键节点、意见领袖、风险判断和干预建议。
2.2 删除或重构能力
原功能	新设计
AI Town 像素地图	改为网络结构可视化图
线上聊天室	改为“全量言论抓取 / 言论洞察”面板
专家会议室	改为“实时传播分析引擎”
专家 Agent 发言	改为后台自动分析情绪、结构、敏感度、连通性、关键节点
地图人物移动	改为节点状态变化与边上传播动画
固定社区场景	改为可切换的网络结构场景

5. 网络结构与场景设定
注意：以下不是照抄传统网络模型，而是把网络结构转译为系统里的场景、人设分布、传播机制和可视化表现。
5.1 随机网络：陌生人广场
场景定位
类似匿名论坛、开放评论区、临时热点话题广场。人与人之间没有稳定关系，连接随机，信息传播依赖偶然接触。
适合研究
text
突发事件刚出现时，陌生用户之间如何快速形成第一波情绪扩散？
人设分布
人设类型	比例建议	行为特征
好奇浏览者	35%	容易接触信息，但不一定传播
情绪放大者	20%	遇到高刺激内容更容易转发
怀疑观望者	20%	会等待更多证据
随机传播者	15%	传播行为受情绪和偶然因素影响
冷处理者	10%	信息疲劳，较少参与
技术参数
json
{
  "network_type": "random",
  "scene_name": "anonymous_public_square",
  "node_count": 80,
  "edge_probability": 0.06,
  "default_trust": 0.35,

}

8. 两个新增核心指标
8.1 意见感知指数 OSI
Opinion Sensitivity Index，表示智能体对他人观点变化的敏感程度。
影响因素
text
1. 邻居中持相同观点的比例
2. 邻居中高影响力节点的观点
3. 最近接触到的信息强度
4. 智能体自身人格
5. 智能体当前情绪唤醒度
计算建议
text
OSI_i(t) =
w1 * neighbor_opinion_pressure
+ w2 * hub_opinion_pressure
+ w3 * content_emotion_intensity
+ w4 * persona_susceptibility
+ w5 * current_arousal
输出范围：
text
0.0 - 1.0
数值越高，代表该智能体越容易受他人观点影响。
8.2 连通性感知指数 CPI
Connectivity Perception Index，表示智能体对自身社会联系重要性的感知程度。
影响因素
text
1. 自身节点度数
2. 是否位于桥接位置
3. 是否连接多个社区
4. 是否被他人频繁引用
5. 最近发言是否引发反馈
计算建议
text
CPI_i(t) =
v1 * normalized_degree
+ v2 * betweenness_centrality
+ v3 * cross_community_links
+ v4 * reply_count_score
+ v5 * perceived_social_responsibility
输出范围：
text
0.0 - 1.0
数值越高，代表该智能体越认为“我的发言会影响别人”。

每个时间步，系统对每个智能体执行一次决策。

9.2 决策输出
json
{
  "action": "share | question | debunk | ignore | modify | wait",

  "emotion_delta": {},

  "confidence": 0.77,
  "target_agents": ["A031", "A044"]

9.3 决策规则
text
传播概率 =
内容刺激度
× 人格传播倾向
× 意见感知指数
× 邻居压力
× 当前情绪唤醒度
× 网络结构修正系数

text
辟谣概率 =
事实核查倾向
× 证据强度
× 连通性感知指数
× 责任感参数
× 对原信息的不信任程度

text
沉默概率 =
信息疲劳
× 风险规避程度
× 低连通性感知
× 低情绪唤醒

18. 方案评估
18.1 优点
这个方向比原方案更适合论文化。原方案更像一个功能展示平台，有采集、聊天室、专家会议和图表；新方案有明确研究变量：
网络结构 → 智能体人格分布 → 个体传播决策 → 群体舆论演化结果
这更容易写成论文中的实验设计。
18.2 和已有舆论传播模型的区别
传统模型通常关注群体比例变化，例如多少人相信、多少人传播、多少人免疫。你的方案可以强调：

单个智能体如何理解内容
单个智能体如何受邻居影响
单个智能体如何根据社会关系决定是否发言
不同网络结构下，个体心理机制如何放大或抑制传播

这个角度更像“基于大模型智能体的微观传播机制仿真”。
18.3 风险
主要风险有三个：
第一，不能只靠 LLM 自由聊天。否则实验不可控，结果难复现。必须用公式、状态机和固定参数约束 LLM。
第二，网络结构不能只是视觉效果。每种网络都必须真正影响传播概率、邻居压力、关键节点、信息路径和人设分配。
第三，论文里不能声称系统能准确预测真实舆情。更稳妥的表述是：
本系统用于解释不同网络结构和个体行为机制下的舆论演化差异，适用于小样本案例推演、机制解释和策略对比，不直接等同于真实平台的大规模预测系统。
18.4 最推荐的论文题目方向
可以考虑：
《基于多网络结构与大模型智能体的公共舆论传播演化仿真研究》
或
《面向公共危机舆情的多智能体传播仿真系统：网络结构、个体认知与干预策略》
18.5 最核心创新点
建议论文主打三个创新：
网络结构驱动的多智能体舆论演化框架

引入意见感知指数和连通性感知指数，刻画个体受他人意见影响和重视社会联系的程度

将言论抓取、情绪分析、传播路径和动态报告合并成可解释的舆论传播分析闭环

我的判断：这个方向是可以继续做的，而且比原来的“AI Town + 专家会议”更像论文系统。关键是把它从展示型项目变成可控实验平台：网络结构可切换，智能体参数可复现，传播过程可记录，结果指标可比较。
